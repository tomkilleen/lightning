    SRTK-30k

    What is this?

    SRTK-30k is a real-time visualiser of every lightning strike detected on Earth. Strikes are rendered on a 3D globe as they happen, accompanied by synthesised audio.

    Data source

    Lightning data is streamed live from Blitzortung.org — a community-run network of hundreds of time-of-arrival sensors operated by volunteers worldwide. Data is free for non-commercial use.

    Technology

    Globe rendering uses globe.gl (Three.js). Coastlines are drawn from the Natural Earth dataset via TopoJSON. Audio is synthesised in real time using the Web Audio API — six voices map strike distance, latitude, and longitude to different synthesis parameters.

    Audio voices

    808 (sub bass with FM), Acid (TB-303 filter sweep), Rave (supersaw hoover), Daft (vocoder FM), Steel (inharmonic partials), Stab (brass chord). Strike distance controls pitch or brightness; geographic coordinates modulate timbre.
